FLYING SHOES + ATTAR — PWA / Installable Web App

This package adds installable PWA support to the store website.
Once the website is hosted on HTTPS:
1. Open its URL in Chrome on Android.
2. Open Chrome menu (three dots).
3. Choose "Install app" or "Add to Home screen" (wording varies).
4. Confirm. The store will appear on the phone like an app.

IMPORTANT:
- This is an installable web app (PWA), not yet a Google Play Store listing.
- Play Store publishing requires a Google Play Developer account and its one-time registration fee.
- Replace demo catalogue data and add the real store WhatsApp number before taking customer orders.
- The website must be hosted over HTTPS for PWA install/service worker support.
- Online payment processing, admin dashboard and server-side order storage are not included yet.
